1.5 Code Quality ESLint & Prettier Checks syntax, style consistency, and code standards.

1.7 SAST Code Scan Semgrep Identifies security anti-patterns and vulnerabilities.
1.8 Unit Tests Jest Executes fast isolated logic tests.
1.9 Integration Tests Supertest / Jest Validates API endpoints (/, /healthz), headers, and status codes.
1.10 E2E Browser Tests Playwright Tests real browser interactions before any container build.
