🚀 Stage Specifications & Quality Gates

1. Automated Testing & Fail-Fast

Every code change runs through isolated automated testing.

  • Dependencies restored via GitHub Actions cache.
  • Unit & integration tests run via npm test.
  • Strict Fail-Fast: Non-zero exit code immediately aborts downstream jobs.

2. Multi-Stage Docker Containerization

Optimized and secured container build.

  • Non-root user execution (security hardening).
  • Build dependencies stripped out of final runtime image.
  • Layer caching enabled (type=gha) for fast builds.

3. Kubernetes Continuous Deployment

Automated declarative cluster synchronization.

  • Manifests: Deployment, Service, Ingress, ConfigMap.
  • Dynamic rollout: kubectl set image or Kustomize.
  • Health probe validation with kubectl rollout status.

4. Google Chat SOAR Notification

Real-time team alerting on every pipeline execution.

  • Always runs on completion (if: always()).
  • Success (🟢): Commit SHA, author, version tag, workflow URL.
  • Failure (🔴): Offending step, failure diagnostics, direct log link.
